Getting the official CUDA code to build on a Blackwell GPU with CUDA 13
took eight fixes, all build flags or environment settings; no source file
of R2-Gaussian, TIGRE or 4DRGS was edited (`git diff` checked after every
run):

| Problem | Fix |
|---|---|
| No nvcc in the image | CUDA 13.0 compiler from NVIDIA's pip wheels, pinned to torch's CUDA version |
| torch missing in pip's isolated build env | `--no-build-isolation` for every CUDA extension |
| nvcc 13.3 picked up against torch cu130 | One CUDA_HOME, nvcc version must equal torch's CUDA |
| `cub/cub.cuh` not found | CUDA 13 moved CCCL to `include/cccl`; added via CPATH / NVCC_APPEND_FLAGS |
| `cuda_runtime.h` not found | nvcc in the venv prefix, cudart in the system prefix; merged into one CUDA_HOME (symlinks) |
| `std::uintptr_t` undefined | `-include cfloat -include cstdint` (GCC 14) |
| simple-knn built but not importable | Import check after each build; `editable_mode=compat` |
| Option B (torch cu128 + CUDA 12.8) | Dead end: PyPI has no CUDA 12.8 nvcc binary |

## 3. Synthetic benchmark

### 3.1 Geometry, stenoses, flow and FFR (Step 1.1)

- LAD centerline and radius from ImageCAS expert labels, reusing the
  owner's earlier code (`cs6999-coronary-centerline`, commit `f17a5f0`).
  ImageCAS labels all coronaries as one class, so the LAD is the most
  anterior long branch from the ostium (most rightward tip of the left
  tree), checked automatically and visually.
- 55 labels tried, 15 rejected (merged trees, radius or length out of
  range, root not at the ostium, 1 visual), 40 LADs kept, 5 stenoses each.
- Stenosis: cosine profile, 30 to 70 % diameter reduction, 5 to 15 mm,
  proximal 60 % of the vessel.
- Flow: rest velocity U(10, 20) cm/s, hyperemia = rest x CFR, CFR
  U(1.5, 4.0) (PUNCH), capped at 0.4 m/s. FFR by Young-Tsai at hyperemic
  flow (the tests reproduce the plan's worked example: FFR 0.856, 0.798,
  0.888).

| Quantity | Range (mean) |
|---|---|
| LAD length | 81 to 165 mm (131) |
| Reference radius at the lesion | 1.24 to 2.55 mm |
| V_rest | 10.1 to 19.9 cm/s (DoD check passed) |
| Q_rest / Q_hyp | 0.57 to 3.40 / 1.19 to 6.94 mL/s |
| FFR | 0.30 to 0.99 (0.81); **35.5 % below 0.80** |
| Transit at rest | 0.28 to 2.0 s; at least 1.9 view intervals per transit with 30 views |

### 3.2 Bolus and rotational DSA (Step 1.2)

- Bolus: PUNCH Eq. 2 (advection-dispersion with the area term) in
  conservative form, superbee-limited finite volumes on a 0.1 mm grid,
  gamma-variate inlet with 5 % noise, D log-uniform around 1e-6 m^2/s.
  Deliberately richer than the plug-flow model FlowSplat fits. Tests:
  arrival through a stenosis equals the plug-flow time within 10 ms; mass
  conserved within 2 %; numerical front width 0.29 mm.
- Rendering: lumen voxels (0.25 mm, partial volume) filled with c(s, t_j)
  for every frame, TIGRE cone beam with the 4DRGS geometry (DSO 750 mm,
  DSD 1200 mm, 133 frames over 198 deg, 4.4 s), 0.64 mm detector pixels,
  R2-Gaussian noise model. View subsets 30 / 60 / 133 with the 4DRGS rule.

| Quantity | Value |
|---|---|
| Péclet number | 3,155 to 153,152 |
| Frames with contrast | 58 to 91 % per case; wash-in and wash-out inside the sweep |
| Rendered | 200 / 200, 2.86 GB, 25.5 min on molab |
| Split (by patient) | 140 / 30 / 30 cases (28 / 6 / 6 patients) |
| Spot checks | 121_0, 122_0, 130_0, 131_0, 135_0: bolus visibly advancing |

## 4. Geometry initialization (Step 2.1)

Pipeline: init volume from the training views (60), centerline (skeleton,
longest path), lumen radius by the half maximum of the cross-section
(scale-free), tube-aligned Gaussians every 0.5 mm with sigma = R / sqrt(2),
4DRGS bounded scaling and the plan's alignment regularizer.

| Run | Init volume | Radius MAE (5 val cases) | Outcome |
|---|---|---|---|
| 1 | Static R2-Gaussian (plan route) | 0.20 to 0.42 mm | **DoD failed**: a static model drifts away from the vessel when fitted to views taken at different times (3D PSNR 34.3 -> 32.3 dB during training) |
| 2 | FDK (plan fallback) | 0.05 to 0.11 mm | Pass; coverage check found 131_0 missing its proximal third with the stenosis |
| 3 | FDK + hysteresis threshold | 0.15 to 0.32 mm | Regression (centerline follows FDK streaks); reverted |
| 4 (final) | FDK, single threshold, 4DRGS view subsets | **0.045 to 0.117 mm (mean 0.076)** | **DoD met** |

Final run per case:

| Case | Radius MAE | Vessel coverage | Lesion coverage | Throat error |
|---|---|---|---|---|
| 121_0 | 0.050 mm | 100 % | 100 % | -0.04 mm |
| 122_0 | 0.117 mm | 88 % | 100 % | -0.48 mm |
| 130_0 | 0.103 mm | 97 % | 100 % | -0.17 mm |
| 131_0 | 0.045 mm | 67 % | 0 % | lesion missing |
| 135_0 | 0.066 mm | 100 % | 100 % | +0.03 mm |

Fallback applied (plan, Step 2.1): "If Gaussians do not align with the
vessel: initialize directly from the ground-truth-free FDK volume skeleton."

## 6. Process notes

- Every design choice is traced in `REFERENCES.md` (paper / section /
  equation, or "Ref: OURS" with the reason; unverifiable items marked
  UNVERIFIED). Base-paper elements adopted: 4DRGS geometry, view-subset rule,
  bounded scaling; R2-Gaussian data format, noise model, rasterizer and
  voxelizer; PUNCH flow ranges and transport equation; TIGRE projector.
- Bugs caught by the tests before they reached results: arc-length bias
  (8 %), throat radius taken at the wrong point, negative FFR, radius array
  not flipped with the centerline, smoothing that flattened the stenosis.
- Paper text drafted: implementation details, dataset (geometry, transport,
  rendering), geometry initialization (`paper/sections/`), with
  `paper/references.bib` (some fields UNVERIFIED).
- Raw molab records: `Experiences/` (index in its README).
